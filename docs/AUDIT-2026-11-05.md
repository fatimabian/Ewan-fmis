# System audit — 5 November 2026

## Changes and findings

- Gallery duplicate detection included archived photos. It now checks active photos only, retaining the parcel lock and within-batch hash check. Removed images can be uploaded again; visible duplicates are skipped. Regression coverage exercises both cases and duplicate files in one batch.
- List filters and pagination now replace the result region without a document reload. Filter forms remain mounted. Unsaved edits inside results prevent replacement, including edits made while a response is in flight. Failures leave entries intact.
- GIS drilldown retains the shared name search and limits the parcel directory to that search. Full-name searches support multiple words and surname-first input. Explicit barangay selection reveals parcel pins without changing the map view. Counters appear below the map; the redundant breadcrumb is removed.
- Report filters use themed downward-opening option lists with scrolling and keyboard controls. Compact overview status bars use a shorter chart rather than a full-width tall card.
- Compact farmer reports avoid fetching documents, photos and crop details they do not display. A regression test limits the compact report to two queries. Bulk RSBSA downloads skip unused preview construction; long PDF tables use ReportLab LongTable. Analytics tabs skip unused report-builder metrics.
- Upload validation says “Choose a file first.” Feedback errors stay inline; successful actions retain the success dialog. Confirmation dialogs remain available.
- The audit found the optional RSBSA record-copy uploader missing from registration. It is restored under Supporting Documents, including existing camera controls and escaped filename review.

## GPS screenshot follow-up

Screenshots may retain a visible DA GeoCamera stamp while losing EXIF metadata. GPS extraction now prefers EXIF and otherwise runs local Tesseract against a bounded, enlarged top-of-photo crop. It requires labelled Latitude and Longitude with valid ranges. OCR coordinates are labelled as such and require the existing confirmation flow before changing a parcel pin. Existing gallery images have a Read GPS stamp retry action. OCR has a five-second timeout and does not send photos to an external service.

The production host must install the local reader before using stamp extraction:

```sh
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-eng
```

Without that executable, normal uploads and EXIF extraction continue, but screenshots cannot be read automatically. A low-resolution or unreadable stamp may still require a clearer image. Tests use a synthetic screenshot; the actual attached screenshot has not been exercised as an uploaded file in this environment.

Final pre-GPS audit suite: **508 tests passed**. Additional GPS extraction and retry tests cover visible stamps, coordinate validation, timeout behavior and the requirement to confirm before moving a pin.
